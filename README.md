# DCPI AI

Asistente Android por voz. Interfaz oscura, reconocimiento de voz, TextToSpeech, Gemini API con clave gratuita del usuario y búsqueda web/YouTube.

Compilar: `gradle assembleDebug --no-daemon`.

La clave Gemini se introduce dentro de la app y no se guarda en el repositorio. La cuota gratuita depende de las condiciones vigentes de Google.
